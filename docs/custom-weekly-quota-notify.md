# 官方周额度 Telegram 提醒

控制台「设置 → 通知 → Telegram Bot」开启「官方周额度提醒」。通知总开关及 Telegram 通道也须开启。

- 检查所有带凭证的 Claude / Codex 槽位的官方账号总周用量，默认每 300 秒查询一次。不发起计费模型探测。
- 剩余额度到达或低于 10%、5%、3%、1%、0% 时通知，同账号同周期每档一次；一次跨过多档只发最紧急的一档。正常周期或两次新鲜零用量确认的提前重置后重新计数。
- 消息包含剩余量、下次官方周期更新时间（明确 UTC+09:00）、重置卡持有数和当前可用数。失败/过期快照不当作零额度。
- Claude 按官方卡片的 `seven_day` 能力和可兑换状态提供按钮；只有五小时能力的卡不能兑换周额度。Codex 使用现有官方重置券接口，兑换后检查窗口数和周用量，结果不明不会报告成功。
- 按钮仅在绑定的个人 Chat ID 私聊开放：点击者、聊天、机器人、原消息、随机动作令牌、账号和官方周期必须全部匹配。群聊可以收到提醒，但不开放卡片兑换。
- 一个机器人只能由一个程序接收回调。已有 webhook 时不会覆盖或删除它；冲突会在通知设置中显示。建议使用专用机器人。
- 不会自动兑换重置卡。点击一次会消耗一张官方卡，官方可能同时重置短周期。兑换前持久化执行标记，重复点击、重启、超时均不会自动再次消费。结果不明请在控制台核查。

新增状态使用独立的 `custom_weekly_quota_notify` 表（定制迁移 008），随数据库备份。配置、bot token 仍使用现有通知设置；公有 API 不回显 token。提醒和动作状态不修改用户套餐的历史消费账本。
