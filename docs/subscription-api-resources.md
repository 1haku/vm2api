# 套餐绑定 API 与槽位

管理员在“订阅管理 → 套餐 → 编辑方案与资源”中，可同时绑定同平台的 OAuth 槽位和 API 端点。API 端点先在 API 页面配置；仅绑定套餐明确选择的端点，普通用户不会获得公共 API 池权限。新建向导也支持纯 API 套餐。

已有订阅、用户分配和密钥不变。订阅密钥自动选择资源，日/周额度、用户及分组 RPM、并发仍共用原有计数。API 别名按所选端点的实际上游模型预留与结算；缺少价格的模型不能使用有限额的套餐。套餐模型名单和密钥模型名单同时生效。

- 默认槽位优先，API 故障切换关闭。可改为 API 优先。
- API 端点的套餐内优先级数字越大越优先，同级轮询。停用、没有可用密钥的端点不会被选中。
- 槽位无法识别但已绑定 API 支持的模型，以及端点前缀模型，直接使用对应 API。
- 开启故障切换后，只在槽位容量不足或上游 429/500/502/503/504，且未发送响应、未产生用量时切换到 API。内容审查、权限、订阅额度、并发/RPM、取消请求不会触发切换。响应已开始（包括保活）后不会重放请求。
- 切换沿用同一请求 ID、并发席位和 RPM 计数；事务内重新校验实际 API 模型预留，账本仅结算一次。
- Messages、Chat Completions、HTTP Responses 使用统一路由。API Responses 保持无状态约束，拒绝访问其他用户可能共用的服务器端 response/conversation/file 等资源。WebSocket Responses、独立 Images/Search 接口仍需绑定槽位；纯 API 套餐不能借用其他槽位。
- 官方周窗口仍由套餐指定的槽位决定，API 用量也计入该窗口。纯 API 套餐使用独立周期。

自定义迁移 010 仅新增套餐资源配置、关联表和日志资源类型/名称；旧套餐默认值保持原有槽位调度。保留现有模型费率、账号凭证和日志，迁移检查对新增默认值做规范化，新增绑定与配置也进入完整性核对。

## Anthropic 余额充足但 Claude Code 返回余额不足

本地订阅额度、Anthropic 赠送 API 额度和购买的预付余额是不同的额度。
Anthropic 的 Max/Ultra/Team 赠送 API 额度覆盖普通 API、Agent SDK 等服务，但不覆盖交互式 Claude Code。仅有赠送额度时，同一 API Key 可以完成普通 API 请求，而 Claude Code 请求返回余额不足。应核对该 Key 所属组织的 Billing 页面中的余额类型和工作区消费限制；不能仅依据总余额判断。

官方依据：https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers

真实 Claude Code 请求应保留客户端身份。网关不会通过删除身份标记把交互式调用伪装成赠送额度支持的用途。若需交互式 Claude Code 的 API 回退，应使用该用途可用的购买余额。无有效 Token 用量的拒绝请求不扣本地订阅额度，且必须释放预留。

诊断应先检查已有错误、官方说明和离线回归；不使用真实凭证进行多组字段枚举测试。
